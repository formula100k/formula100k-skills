# Autopilot F100K — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a family of 6 Claude Code skills that create a fully automated daily/weekly content routine for F100K students — from viral monitoring + reaction scripts (daily) to calendar generation, trend alerts, community digests, and metrics reports (weekly).

**Architecture:** One master onboarding skill (`rutina-maestra-formula100k`) saves user config to `~/.f100k-radar/config.json` and schedules all modules via `/schedule`. Each module skill is self-contained: loads config, executes its task (using Apify, Tavily, Gmail MCP), and sends an email digest. Phase B migrates cron invocation to Vercel without touching the skill logic.

**Tech Stack:** Claude Code skills (SKILL.md), Apify MCP (`clockworks/tiktok-scraper`), Tavily MCP, Gmail MCP (`mcp__claude_ai_Gmail__create_draft`), `/schedule` skill, config stored in `~/.f100k-radar/config.json`, existing skills `guionizacion-formula100k` + `calendarizador-contenido-formula100k` as dependencies.

## FASE 2 — CAZA DE VIRALES

### Paso 2A — TikTok via Apify

Para cada keyword en `config.keywords`, lanzar búsqueda en Apify usando el actor `clockworks/tiktok-scraper`:

```json
{
  "searchQueries": ["[keyword]"],
  "resultsPerPage": 15,
  "shouldDownloadVideos": false,
  "shouldDownloadCovers": false
}
```

Filtrar resultados:
- Publicados en las últimas 48 horas (usar campo `createTime`)
- Views mínimo: 100,000 (bajar a 50,000 si ninguno supera el umbral)
- Conservar: URL, título/caption, views, likes, shares, autor, fecha

Consolidar todos los resultados en una lista `tiktok_candidates`.

### Paso 2B — Noticias y YouTube via Tavily

Lanzar 2 búsquedas con Tavily `tavily_search`:

Búsqueda 1 (nicho general):
```
query: "[niche] viral tendencia hoy [fecha_hoy]"
search_depth: "advanced"
max_results: 5
```

Búsqueda 2 (IA + herramientas, si el nicho incluye "ia", "inteligencia artificial", "contenido", "marketing"):
```
query: "nueva herramienta inteligencia artificial viral [fecha_hoy]"
search_depth: "advanced"
max_results: 5
```

Conservar: URL, título, snippet, fuente, fecha.
Consolidar en lista `news_candidates`.

## FASE 3 — ELEGIR EL GANADOR DEL DÍA

### Paso 3 — Scoring y selección

Evaluar TODOS los candidatos (TikTok + noticias) contra estos criterios:

| Criterio | Peso | Cómo evaluar |
|----------|------|--------------|
| Relevancia al nicho del usuario | 40% | ¿Conecta directamente con `config.niche`? |
| Potencial de reacción | 30% | ¿El usuario puede agregar perspectiva única y diferente? |
| Viralidad actual | 20% | Views/likes para TikTok; autoridad del medio para noticias |
| Frescura | 10% | ¿Publicado en las últimas 24h? (+bonus) |

Asignar puntuación del 1-10 a cada candidato y elegir el TOP 1.

Si hay empate: preferir el que tenga mayor potencial de reacción (criterio 2).

Guardar en `winner`: título, URL, métricas clave, tipo (TikTok o noticia), por qué ganó.

## FASE 4 — GENERAR GUION DE REACCIÓN

### Paso 4 — Escribir el guion con la voz del usuario

Usando los patrones de `guionizacion-formula100k`, crear un guion de reacción de 45-60 segundos:

**Estructura del guion de reacción:**

```
[GANCHO VISUAL — 0-3s]
Mostrar o mencionar el viral. Ej: "Acabo de ver esto y no me lo podía creer..."
→ Usar el título o dato más impactante del viral para abrir.

[CONTEXTO — 3-8s]
1-2 líneas de qué es el viral y por qué está trending.

[TU PERSPECTIVA ÚNICA — 8-40s]
3 puntos de vista propios sobre el viral.
Estructura: "Lo que nadie dice sobre esto es... / Esto demuestra que... / Y lo que yo haría diferente es..."
Usar voz del usuario: [voice_profile]
Conectar con el nicho: [niche]

[CTA — 40-55s]
Pregunta de engagement que invite a comentar.
Usar patrón CTA ganador F100K: pregunta de 1-2 sílabas + "comenta [PALABRA] y te cuento más"
```

El guion debe:
- Estar en español neutro (no argentino, no regional)
- Sonar como lo escribió el usuario (usar `voice_profile`)
- Tener máximo 120 palabras totales (para 45-60s de habla)
- Incluir marcas de acción: [PAUSA], [SEÑALAR PANTALLA], [ZOOM IN], etc.

# Skill: Radar de Tendencias Emergentes — Autopilot F100K

La diferencia entre ser el primero y ser el décimo en hablar de algo es 48 horas. Este módulo detecta lo que está despegando AHORA en tu nicho para que publiques antes de la ola, no después.

## FASE 2 — DETECCIÓN DE TENDENCIAS

### Señal 1 — TikTok: crecimiento acelerado (últimas 24h vs semana)

Buscar con Apify `clockworks/tiktok-scraper` para cada keyword:
```json
{
  "searchQueries": ["[keyword]"],
  "resultsPerPage": 50,
  "shouldDownloadVideos": false
}
```

Analizar el patrón de publicación:
- ¿Cuántos videos de este tema en las últimas 6h vs las últimas 48h?
- ¿Hay un spike notable? (más de 3x el promedio diario = tendencia emergente)
- ¿El video más reciente tiene ya muchos shares en poco tiempo?

### Señal 2 — Noticias y web: velocidad de propagación

Tavily `tavily_search`:
```
query: "[niche keyword] [keyword 2] últimas horas breaking"
search_depth: "advanced"
max_results: 8
```

Evaluar: ¿cuántas fuentes distintas cubren el mismo tema en las últimas 24h?
- 1-2 fuentes = notica normal
- 3-5 fuentes = tendencia emergente ⚠️
- 6+ fuentes = tendencia confirmada 🔥

### Señal 3 — Búsqueda de términos nuevos/slang

¿Han aparecido términos nuevos en los captions de TikTok que no estaban en los resultados de la semana pasada?
Si sí → posible micro-tendencia léxica (ej: nuevo nombre para algo conocido, nuevo meme-format).

---

## FASE 3 — CLASIFICACIÓN Y ALERTA

Clasificar hallazgos:

| Nivel | Criterio | Acción |
|-------|----------|--------|
| 🔥 CALIENTE | Tendencia confirmada (6+ fuentes o spike 5x) | Alerta URGENTE — publicar HOY |
| ⚠️ DESPEGANDO | Tendencia emergente (3-5 fuentes o spike 3x) | Alerta — publicar en 24-48h |
| 👀 OBSERVAR | Señal débil (1-2 fuentes o novedad léxica) | Mención informativa |

Si NO hay ninguna tendencia emergente → no enviar email (silencio = sin spam).

**Tipo D — Validaciones y peticiones** ("Hazme un video de X", "Me encantó, quiero más de Y")

Contar frecuencia de cada tema. Los top 5 temas = ideas de contenido con demanda probada.

- ¿El CTA? (pregunta que generó comentarios)

Comparar con el peor post de la semana: ¿cuál es la diferencia clave?

**Promedio de la semana vs semana anterior** (si hay datos):
