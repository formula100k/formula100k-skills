# Ejemplo resuelto · Dollar Shave Club

El caso que sirvió de molde para el estilo. Úsalo para ver cómo se arma un expediente: el guion (`guion.txt`), la pieza comentada frase por frase (`../plantilla/fuente/pieza.src.html`), la tabla de etiquetas (`etiquetas_A.md`) `cuadros.jpg` (8 cuadros del video terminado) y, abajo, de dónde sale cada cifra y cada imagen. Las imágenes del ejemplo no vienen con la skill porque son de terceros: para tu caso consigues las tuyas.

## Ganchos A/B/C
- **A (principal):** «$4.500 VALIERON / MIL MILLONES». Lleva las dos cifras reales (la inversión y el resultado), las dos líneas se leen como una frase y la voz arranca diciendo lo mismo.
- **B:** «MIL MILLONES / POR UN VIDEO».
- **C:** «12.000 PEDIDOS / EN DOS DÍAS».

B y C son más cortas pero cuentan una sola cifra. Las tres sirven para subirlas como prueba (trial reels) y ver cuál retiene más.
